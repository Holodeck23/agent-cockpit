Before you take off

  • 01 A Mac with Apple silicon.
    Intel, Windows and Linux aren’t supported.
  • 02 Claude Code or Codex installed and signed in. At least one is required.
  • 03 Your own agent access.
    Provider subscriptions and limits still apply.
01 / INSTALL

Make yourself at home.

Open the DMG and drag Cockpit into Applications. Then open Cockpit.

02 / FIRST LAUNCH

Let your Mac know.

If macOS blocks the app, choose Done. Go to System Settings → Privacy & Security → Open Anyway, authenticate, then confirm.

03 / FIRST CONVERSATION

Start with something small.

Open a project folder, choose your installed agent, and use Ask before acting. Ask it to get your dev server running.

A few things to know

Early build.
Clear expectations.

Does Cockpit include an AI subscription?

No. Cockpit uses the official Claude Code and Codex CLIs you install and sign into. Usage is billed or counted by those providers. Cockpit doesn’t supply model access or bypass usage limits.

Where does my work go?

Projects stay in the folders you choose. Cockpit keeps conversation metadata, events and readable Markdown transcripts under ~/.agent-cockpit/ on your Mac. Prompts and attached context go to your selected agent’s provider. There is no Cockpit cloud account or cloud storage.

What should I expect from the prerelease?

v0.1.0 has been tested on one Apple-silicon Mac. It isn’t notarized and has no automatic updates. Many simultaneous agents haven’t been stress-tested. Agent switching is manual, and previews open in your browser. Deny and Allow for this session are implemented but weren’t part of release testing. Read the full release notes before installing.

Can I check in from my phone?

Optional phone access uses your own Tailscale account. Pair your phone to follow conversations, reply, approve requests and stop a turn. Keep your Mac awake and Cockpit running. Physical-phone push notification delivery is not yet verified.

How do workflows run?

Save a set of instructions and agent settings, then run it manually or on a repeating interval. Cockpit must remain open. Schedules pause on failure; calendar schedules such as “every weekday at nine” are not included in this release.

Is this related to Enjoy?

Cockpit is an independent project inspired by Enjoy’s layout and interaction model. It is not affiliated with Enjoy. Cockpit’s code, name, mark and copy are its own; no Enjoy code or assets were taken.

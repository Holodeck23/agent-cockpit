  • A current Claude Code, Codex, OpenCode or Antigravity CLI, installed and signed in.
  • Your own agent access. Provider subscriptions and limits still apply.

Installed from Terminal, Cockpit opens on the first try. From the DMG, if macOS blocks it, choose Done, then System Settings → Privacy & Security → Open Anyway.

A few good
questions.

Does Cockpit include an AI subscription?

No. Cockpit runs the agent CLIs you install and sign into: Claude Code, Codex, Antigravity and OpenCode, including configured OpenRouter models. Usage is billed or counted by those providers; Cockpit doesn’t supply model access or lift usage limits.

Where does my work go?

Projects stay in the folders you choose. Conversation metadata, events and readable Markdown transcripts live under ~/.agent-cockpit/ on your Mac. Prompts and attached context go to your selected agent’s provider. There is no Cockpit cloud account or cloud storage. One exception, as a condition of the beta: crash and error reports go to Cockpit’s developer through Sentry (EU region), with no setting to turn them off. A report holds the error and its stack trace, Cockpit’s version, and the macOS version and kind of Mac. Your home folder is replaced with ~; file contents, screenshots and the machine name are never sent, though error text can name a project or file. See the beta terms.

What should I expect from the prerelease?

An early build. It is ad hoc signed and not notarized, and it runs on your own agent accounts and provider limits. Independent other-Mac acceptance, two hours of real use, physical-phone push, live Chrome and account checks and OpenCode’s live OpenRouter path are still open. The browser demo uses current development UI and scripted local data, so it doesn’t establish those checks. Read the full release notes before installing.

Can I check in from my phone?

Optional phone access runs over your own Tailscale account: follow conversations, reply, approve requests and stop a turn. Keep your Mac awake with Cockpit running. Push notification delivery to a physical phone is not yet verified.

How do workflows run?

Save instructions and agent settings, then run them manually, on an interval, daily, on weekdays or on selected days at a local time. Cockpit must be running. After downtime at most one missed run starts; failed runs report their errors and don’t block future runs.
